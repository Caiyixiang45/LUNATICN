# 04 联机流程

LUNATICN 提供两种联机方式：**房主开服**（玩家自己开房）与**固定服务器**（官方常驻服）。两种方式在大厅里分列两个页签。

## 一、房主开服（source=launcher）

### 时序

```
房主启动器                社区服务端                Luanti 引擎(服务端)         加入者
   |                        |                          |                      |
   | 1. 创建房间(选存档)      |                          |                      |
   |---- EnsureEngine ----->| (本地检查/下载引擎)        |                      |
   | 2. 启动 luanti --server |                          |                      |
   |------------------------|------------------------->| 监听 30000/udp       |
   | 3. POST /api/room/register                        |                      |
   |------------------------>| 记录房间, 返回 room_token |                      |
   | 4. 心跳 POST heartbeat(每 10s, 带在线人数)          |                      |
   |------------------------>| 刷新房间状态并广播         |                      |
   |                        |                          |                      |
   | 5. 大厅出现房间(WS 推送 {"type":"rooms"})           |                      |
   |                        |<-------------------------|----------------------|
   |                        | GET /api/rooms           |                      |
   |                        | 6. host:port 给加入者     |                      |
   |                        |                          |<-- 7. UDP 连接 ------|
```

### 关键实现（启动器）

- `RoomHostService.StartAsync(roomName, worldDirName, gameId, port, maxPlayers, hasPassword, isPrivate, description)`
  1. `EngineManager.EnsureEngineAsync` 确保引擎可用；
  2. 以 `--server --world <世界目录> --gameid <游戏> --port <端口>` 拉起进程，捕获标准输出逐行回传 UI；
  3. 调用 `POST /api/room/register`，`host` 取本机 LAN IP（UDP connect 8.8.8.8:53 探测）；
  4. 启动心跳定时器，人数变化随心跳上报。
- 关闭：`StopAsync` → `POST /api/room/unregister` → 结束进程。

### 网络要求

- 默认端口 **30000/udp**（Luanti 主端口），可改。
- 房主需在防火墙放行该端口；局域网直接可玩，跨网需要公网 IP 或内网穿透。
- 加入者无需开放端口。

## 二、固定服务器（source=fixed）

### 服务端守护

社区服务端配置 `fixed_servers`：

```json
{
  "fixed_servers": [
    { "name": "官方一服", "port": 30000, "world": "official1", "gameid": "minetest", "max_players": 16 }
  ]
}
```

`internal/fixedserver.Manager` 负责：

1. 启动时按配置拉起每个 `luanti --server`；
2. 进程意外退出自动重启（带退避）；
3. `GET /api/servers` 返回名称、端口、运行状态；
4. 服务端退出时 `StopAll` 全部关闭。

### 加入流程

1. 大厅"官方服务器"页签调用 `GET /api/servers`；
2. 点击"进入"→ `JoinService.JoinAsync(host, port, playerName)`；
3. 启动 `luanti --go --address <host> --port <port>`，玩家昵称取设置页配置。

## 三、加入房间的完整判断

```
选中房间 → 是否有密码? (当前版本启动器统一走无密码流程, 后续版本接入)
        → JoinAsync(host, port)
        → EngineManager 确保引擎
        → 进程启动 luanti --go --address --port
        → 玩家进入游戏
```

失败处理：连接超时/进程秒退时状态栏展示 `连接失败: <原因>`。

## 四、大厅实时刷新

1. 启动器连接 `GET /api/ws`；
2. 服务端在房间注册、心跳人数变化、注销、超时清扫时广播 `{"type":"rooms"}`；
3. 启动器收到后重拉 `GET /api/rooms`，绑定到房间列表；
4. 手动"刷新"按钮同样调用该接口。

## 五、私密房间

- 创建房间时勾选"仅好友可见"→ `private=true`；
- 服务端列房间时若请求带登录态，`private=true` 的房间只对房主本人与其好友返回；
- 匿名请求看不到任何私密房间。

## 六、端口与协议速查

| 用途 | 协议 | 端口 | 说明 |
|------|------|------|------|
| 社区服务端 | TCP | 8080 | HTTP/WS，启动器与 roomd 访问 |
| Luanti 游戏 | UDP | 30000 | 每个房间/固定服一个，可并行多开需不同端口 |
| 房主本地管理 | - | - | 进程 stdout 回传，不占端口 |

## 七、排错

| 现象 | 排查 |
|------|------|
| 房间列表不出现自己开的房 | 看启动器状态栏注册错误；确认社区服务端地址设置正确 |
| 大厅看不到房间变化 | 看 WebSocket 是否连接（F12/日志）；确认服务端未加反代且反代支持 Upgrade |
| 加入失败 | 确认房主端口放行 UDP、host 用的是 LAN IP 还是公网 IP |
| 引擎起不来 | 设置页"重新下载引擎"；检查 aria2c 路径或网络 |
