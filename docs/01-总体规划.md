# 01 总体规划

## 一、项目定位

LUNATICN 是基于 [Luanti](https://luanti.org) 引擎二次封装的私有沙盒游戏平台。项目不修改引擎源码，引擎由启动器在用户首次运行时自动下载官方便携版。平台补齐引擎本身缺少的"账号、好友、房间、分享"等社区能力。

## 二、目标与范围

### 目标

1. 让玩家在 Windows 上一键安装、一键联机，无需手动配置引擎。
2. 提供自建账号体系（用户名密码，不依赖第三方登录）。
3. 提供地图与模组的分享生态（打包、上传、检索、下载）。
4. 联机采用"房主开服 + 官方固定服务器"双轨制，兼容不同规模的游玩场景。
5. 全部服务端组件可自托管，数据完全私有。

### 不做的事

- 不修改、不重新编译 Luanti 引擎。
- 不做公网商业化运营（当前阶段为私有部署）。
- 不引入第三方账号体系（微信 / QQ / Steam 等）。

## 三、项目组成

| 组件 | 技术栈 | 仓库 | 可见性 | 说明 |
|------|--------|------|--------|------|
| 客户端 | Python 3.13 / DearPyGui | LUNATICN-server | 私有 | 大厅、存档、模组、工坊、好友、设置（毛玻璃 UI） |
| 社区服务端 | Go 1.23 | LUNATICN-server | 私有 | 账号、好友、房间注册中心、分享、固定服守护、WebSocket、公告与更新推送 |
| 房间服务器 | Go 1.23 | LUNATICN | 公开 | 独立轻量房间服务器 roomd，开源 |
| 历史归档 | - | LUNATICN-archive-old | 私有 | 旧仓库改名归档，保留历史 |
| 旧版客户端 | C# / WPF / .NET 9 | LUNATICN-server | 私有 | `launcher/` 保留备选，主线为 Python 客户端 |

公开仓库 LUNATICN 只包含 roomd 与其文档；完整项目只存在于私有仓库 LUNATICN-server。

## 四、核心功能清单

1. **账号**：注册、登录、JWT 保持、昵称与密码修改（argon2id 哈希）。
2. **联机大厅**：房间列表（WebSocket 实时推送）、创建房间、加入房间、心跳保活、私密房间仅好友可见。
3. **固定服务器**：服务端守护进程托管若干固定服，掉线自动拉起，启动器一键进入。
4. **存档库**：新建、进入、复制、删除、导入（zip / .lnpkg）、分享导出。
5. **模组中心**：安装、卸载、依赖解析、按存档启用（读写 `world.mt`）。
6. **分享工坊**：地图与模组打包上传 `.lnpkg`、关键词检索、一键下载入库、作者删除。
7. **好友**：按用户名添加、申请列表、接受 / 拒绝、删除、邀请进房。
8. **引擎托管**：多镜像兜底下载官方 Luanti 便携版（GitHub 直连失败自动切镜像）、ContentDB 安装游戏（主游戏 Mineclonia）、版本探测。
9. **设置**：社区服务器地址、游戏昵称、客户端端口、目录快捷打开。
10. **公告与更新推送**：服务端发布公告与客户端新版本，WebSocket 实时推送，更新包多下载源逐个兜底。

## 五、关键约束（硬性）

1. **禁词**：文档、README、代码、仓库描述中不得出现特定竞品名称。检测采用码点构造方式，不打印原词。
2. **编码**：所有文本文件一律 UTF-8 无 BOM；PowerShell 向外部程序传中文必须用 `\uXXXX` 转义或走文件字节，避免 PS 5.1 参数乱码。
3. **开源边界**：仅 roomd 公开；账号、密钥、部署脚本、启动器源码全部私有。`jwt_secret` 等敏感配置不入库。
4. **零引擎侵入**：所有能力通过命令行参数、`world.mt`、世界目录实现，不 fork 引擎。

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| Luanti 官方下载源变更 | 下载 URL 集中在 `download.py`，多镜像链逐个兜底（直连 → gh-proxy → ghproxy.net），失败回退 GitHub API 查询最新版 |
| 端口占用 / 防火墙拦截 | 房间端口可配置，文档给出放行说明 |
| 私有仓泄露凭据 | `.gitignore` 排除 config.json、data/；PAT 只存 Windows 凭据管理器 |
| PS 中文编码 | 统一 `\uXXXX` 转义，所有脚本走文件 |
