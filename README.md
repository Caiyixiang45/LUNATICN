# LUNATICN

基于 [Luanti](https://luanti.org) 引擎二次封装的沙盒游戏平台，UI 与功能对标《迷你世界》0.44.2 的布局逻辑。

## 项目组成

| 目录 | 技术栈 | 说明 |
|------|--------|------|
| `launcher/` | C# WinUI 3 (.NET SDK 9) | 启动器：登录、联机大厅、存档库、模组中心、工坊、好友、设置 |
| `server/` | Go | 独立服务端：账号认证、房间大厅、地图/模组分享、固定服务器守护、好友邀请 |
| `docs/` | Markdown（中文） | 总体规划、架构设计、API 文档、联机流程、分享包格式 |

## 核心功能

- **模组管理**：本地模组库安装/卸载/启用，依赖自动解析，按存档读写 `world.mt`
- **联机**：房主开服制 + 官方固定服务器制，房间列表实时刷新，好友邀请
- **存档**：世界的新建/进入/复制/导出/删除
- **分享**：地图与模组打包上传（`.lnpkg`）、浏览搜索、一键下载
- **引擎托管**：首次运行自动下载官方 Luanti 便携版，零修改引擎源码

## 快速开始

### 服务端（Go）

```powershell
cd server
go run ./cmd/server -config config.yaml
```

### 启动器（WinUI 3）

```powershell
cd launcher
dotnet build
```
